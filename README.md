# Orbit Sandbox (PWA)

Mobile-first gravity sandbox built with **Vite + TypeScript + PixiJS**. Drag stars and planets into the scene and let their mutual gravity create chaotic motion.

## Quick start

```bash
npm install
npm run dev
```

Production build and preview:

```bash
npm run build
npm run preview
```

## Deploy to GitHub Pages

This repo includes `.github/workflows/deploy-pages.yml` to publish `dist/` to GitHub Pages on pushes to `main`.

1. Push this repo to GitHub.
2. In GitHub, open `Settings -> Pages`.
3. Set `Source` to `GitHub Actions`.
4. Push to `main` (or run the workflow manually from `Actions`).

Notes:
- Vite base path is auto-set during GitHub Actions builds to `/<repo>/` for project pages.
- For a custom base path, set `VITE_BASE_PATH` in workflow/repo variables.
- For `username.github.io` repos, base stays `/`.

## Controls

- Drag a movable star to reshape gravity fields.
- Drag existing stars and planets to reposition them before releasing.
- Drag a body card from the bottom palette into the playfield to spawn that type.
- Star cards spawn movable gravity sources that drift more slowly than planets.
- `Pause`, `Restart`, `Trails`, and `Preview` are available in HUD.
- While dragging a star, simulation runs in bullet-time and preview trajectories appear.

- Star archetypes: `src/game/starTypes.ts`
- Gravity/chaos tuning: `src/core/config.ts`

## PWA + offline behavior

- Manifest: `public/manifest.webmanifest`
- Service worker: auto-generated by `vite-plugin-pwa` in `vite.config.ts`
- App shell and assets are precached after first load.
- JSON/image runtime caching is configured via Workbox rules.
- Offline badge appears in HUD when `navigator.onLine === false`.

### Verify offline

1. `npm run build`
2. `npm run preview`
3. Open app once while online.
4. In DevTools, switch network to Offline.
5. Reload; the game should still start and run.

## iOS Safari / iOS PWA troubleshooting

- Use iOS 16+ Safari when possible.
- If touch drags scroll the page, ensure the app runs full-screen and `touch-action: none` remains on canvas/game root.
- If stale assets appear after deploy, close the PWA and reopen (SW update cycle on iOS can lag).
- If install prompt is not shown, use **Share -> Add to Home Screen** manually.

## Notes

- Physics model is game-oriented, not physically exact.
- Planets and stars both contribute to gravity.
- Fixed timestep simulation runs at 60 Hz and automatically drops render cap to 30 FPS on slower devices.
